# Скрипты

Каталог зарезервирован под установку и лабораторные сценарии Linux.

Планируется:

- установка сервера на Ubuntu 24.04: пользователь, каталоги, юнит systemd;
- лабораторный прогон с `ip netns` и `tc netem`: задержка, потери, ограничение скорости, обрыв маршрута.

Скриптов ещё нет. Пока сборка и запуск описаны в корневом `README.md`.

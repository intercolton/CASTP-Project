# systemd

Юниты рассчитаны на установку бинарников в `/usr/local/bin` и конфигурации в `/etc/astp-probe`. Каталог данных в примерах TOML — `/var/lib/astp-probe`.

`astp-probe run` внутри клиентского юнита ещё не выполняет расписание: процесс сразу завершится с сообщением, что этап не реализован. Серверный юнит можно использовать после сборки `astp-probe-server`.

На чистой Ubuntu 24.04 эта установка пока не прогонялась.

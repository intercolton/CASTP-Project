# Безопасность

- TLS проверяется всегда. Режим «принять любой сертификат» не предусмотрен.
- Для цели по IP в конфигурации задаётся `tls_server_name`. Проверка идёт по этому имени, а не отключается.
- Свой сертификат тестового сервера подключается через `ca_file`. Остальные якоря для этой цели тогда не используются.
- В журналы не пишутся токены, ключи и содержимое чужих соединений.
- Поле `peer` на стороне сервера нужно для разбора инцидента. В отчёт его не переносят без отдельного решения.
- Сервер не выполняет команды из запросов клиента.
- Число соединений и объём тестовых данных ограничены конфигурацией.
- Административный порт и публичные диагностические порты в конфигурации не могут совпадать.
- Остановка сервера: SIGINT или SIGTERM. Процесс перестаёт принимать соединения и сбрасывает журнал.

Токен телеметрии, когда приём будет реализован, хранится в переменной окружения `ASTP_TOKEN`, не в TOML.

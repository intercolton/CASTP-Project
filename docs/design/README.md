# Проектирование ASTP-M v1

Документы этого каталога фиксируют решения, по которым написан код `astp-session`, `astp-transport`, `astp-tun`, `astp-server` и `astp-client`.

Статус каждого решения:

- **принято** — следует из уже зафиксированного в README или спецификации, код на нём построен;
- **предложение** — выбрано автором кода как наиболее разумный вариант, код на нём построен, но решение ждёт утверждения владельцем; смена решения означает правку кода;
- **отложено** — к v1 не относится, кода нет.

| Документ | О чём | Статус |
|---|---|---|
| [scope.md](scope.md) | Что входит в v1: односерверная схема (п. 2.1 ревью) | принято |
| [session.md](session.md) | Установка сессии внутри HTTP/2 и HTTP/3, жизненный цикл, кадры, поток данных | предложение |
| [credentials.md](credentials.md) | Боевой формат учётных данных и привязка к каналу | предложение |
| [network.md](network.md) | TUN, адреса, маршруты, маршрутизация на сервере | предложение |
| [split-path.md](split-path.md) | Каскад: склейка двух соединений и путь управляющих кадров (пп. 2.4, 2.5) | отложено, есть предложение |
| [STATUS.md](STATUS.md) | Что сделано и что дальше | — |

# Интеграционные тесты

Сквозной прогон клиента и сервера на localhost лежит в `crates/probe-server/tests/integration.rs`. Cargo видит его как тест крейта `probe-server`.

Сюда, в каталог репозитория, попадут сценарии, которым тесно внутри одного крейта: `tc netem`, сетевые пространства имён и сверка измеренной задержки с заданной. Этих сценариев ещё нет.
